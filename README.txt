GAPPU BIRTHDAY WEBSITE

1. Extract gappu_birthday_website.zip.
2. Keep index.html and the assets folder together.
3. Open index.html in Chrome, Edge, or another browser.
4. The four uploaded photos are already included in assets/.

To change the photos, replace the files in assets/ but keep the same filenames.
The page uses Google Fonts when internet is available; the website still works offline with fallback fonts.
